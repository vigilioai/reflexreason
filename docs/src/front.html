An on-call triage system for a Kubernetes cluster in which the fast path never waits for a language model. A decision model on CPU matches a fault to a known procedure in about {{med([r.records[0].ms.decide for r in R.scen.results if r.agents == 1]) / 1000|.1f}} seconds, a guarded tool applies the fix, and a language model is consulted only when nothing known fits. Most of the code is TypeScript. Three small Rust programs sit where the measurements said they had to.

Every number on this page was measured on one machine: {{R.cold.machine.vcpus}} vCPUs of an {{R.cold.machine.cpu}}, {{R.cold.machine.mem_mb|,}} MB of memory, Linux {{R.cold.machine.kernel}}, Node {{R.cold.machine.node}}, {{R.cold.machine.rustc.split(" (")[0]}}, Kubernetes {{R.scen.cluster.split('"')[3]}}. The raw results are in bench/results/, and this page is generated from those files by docs/build_tutorial.py. No GPU was available on that machine; what that leaves unverified is listed in the last chapter.
